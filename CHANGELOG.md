# Histórico de alterações

Este arquivo resume as mudanças relevantes do MatchPoint, preservando a evolução do aplicativo.

## V10 — versão de testes

### Interface e experiência
- Nome e identidade visual **MatchPoint**.
- **⚡ Placar rápido** com layout mais compacto, ícone de raio, nomes e cores de equipes.
- Placar em tela cheia, com animação mecânica de virar folha e inversão dos lados.
- Arrastar jogadores com prévia acompanhando o dedo e destaque do destino.

### Organização das partidas
- Cadastro e seleção de turmas.
- Registro de presença e chegada tardia.
- Sorteio de equipes, montagem manual e edição das escalações.
- Fila de espera, histórico de partidas e ranking.

### Repositório
- Documentação consolidada no README.
- Padronização do nome do projeto Gradle.
- Workflow de compilação revisado para a branch principal e pull requests.
- Inclusão de arquivos de exclusão do Git e remoção de instruções desatualizadas.

> **Observação:** o aplicativo ainda utiliza armazenamento local e APK de depuração. Estas notas descrevem o estado do projeto, não uma distribuição estável de produção.
